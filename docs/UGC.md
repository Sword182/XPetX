# XpetX UGC（用户生成内容）规范

UGC 指用户为 XpetX 制作的内容：**宠物包**、**手势/动画配置**、**专属预览图**等。
项目已预留 `XpetX\UGC\` 目录，本规范定义其结构约定，后续批次接入加载逻辑。

---

## 一、目录结构约定

```
UGC\
├── pets\                  # 宠物包目录（与内置 pets 同构）
│   └── <petId>\
│       ├── spine\         # Spine 素材（必需）
│       │   ├── xxx.skel   # 骨骼数据（二进制，3.8 格式实测兼容）
│       │   ├── xxx.atlas  # 图集描述
│       │   └── xxx.png    # 图集纹理
│       ├── name.json      # 注册名称文件（真实显示名，见下）
│       ├── preview.png    # 专属预览图（可选，菜单预览优先使用）
│       ├── gestures.json  # 手势→动画映射（可选，见下）
│       ├── @HYPERGRYPH    # 版权声明（受版权保护的角色必需，见下）
│       └── save.json      # 运行期存档（自动生成，勿手动编辑）
├── gestures\              # 全局手势/动画配置（可选）
└── config.json            # 该用户的全局配置覆盖（可选）
```

## 二、宠物包（UGC/pets/<petId>）

### 文件夹命名规则

- 文件夹名**只允许英文、数字、`_`、`-`**（如 `pet-001`、`skadi_v2`）。
- 其他字符的文件夹会被应用**忽略**（不读取）。

### 注册名称文件 name.json

文件夹名仅作内部标识；**真实显示名**由包内 `name.json` 提供：

```json
[
  {
    "reg": "skadi",
    "CN": "斯卡蒂",
    "EN": "Skadi",
    "JP": "スカジ",
    "KR": "스카디",
    "TW": "斯卡蒂"
  }
]
```

- `reg`：注册名（英文标识）。
- `CN` / `EN` / `JP` / `KR` / `TW`：各语言显示名。
- 应用按系统语言选择对应字段（zh 系优先 CN，zh-TW/HK 用 TW，ja→JP，ko→KR，其他→EN）；
  缺失时回退 `reg` → 文件夹名。
- 没有 `name.json` 的宠物直接使用文件夹名作为显示名。


### 必需内容

- `spine\` 子目录，内含一套 Spine 素材：`.skel`（或 `.json`）、`.atlas`、`.png`。
- 目前运行时以 3.8 二进制（`.skel`）验证；4.x 素材需配套 4.x 运行时（当前内置 3.8 运行时）。

### 可选内容

- **专属预览图**：`preview.png`（或 jpg/jpeg/bmp/gif），放宠物目录或 `spine\` 下；
  存在时菜单预览使用它，否则回退到图集 PNG。
- **gestures.json**：手势/行为 → 动画名的自定义映射（结构见下节）；缺失时用内置回退规则。

### 命名约定（无 gestures.json 时的回退）

| 行为 | 期望动画名 | 回退顺序 |
| --- | --- | --- |
| 待机 | `idle` | `idle` → `Relax` → `Default` → 素材第一个动画 |
| 行走 | `Move` | 无左右变体时由 `walkMirror` 翻转 |
| 睡觉 | `Sleep` | — |
| 坐下 | `Sit` | — |
| 开心/互动 | `Interact` | — |

骨骼约定（光标追踪）：眼珠骨骼名含 `eye`；无眼珠骨骼时用含 `head` 的骨骼。
（详见 [`config.md`](config.md) 第三节。）

## 二·五、版权声明（受版权保护的角色必需）

如果宠物是**受版权保护的角色**（例如明日方舟干员），宠物包内**必须**放置一个**以 `@` 开头的空文件**，
文件名即版权方，文件本身**无内容**（空格式文件）。示例：

- 明日方舟干员（Skadi 等）：`@HYPERGRYPH`
- 其他角色的版权方照此办理：`@版权方名称`

规则：

1. 文件无内容，仅作声明；放在宠物包根目录。
2. 菜单预览卡会显示版权方名（如 `@HYPERGRYPH`，不带 © 符号）。
3. 没有版权声明文件的宠物包视为原创/无版权角色（仍需遵守素材自身许可）。

## 三、gestures.json（可选）

结构：

```json
{
  "idle": "Relax",
  "walk": "Move",
  "sleep": "Sleep",
  "sit": "Sit",
  "happy": "Interact",
  "curious": "Interact",
  "eat": "Default",
  "sad": "Default",
  "dizzy": "Default",
  "disgust": "Default"
}
```

- 键为行为名，值为素材中的动画名。
- 只写需要覆盖的键即可；缺失键走内置回退规则。
- **实现状态**：加载逻辑尚未接入（当前读取内置 `pets\` 目录）；接入后优先读取该文件。

## 四、配置

- 全局：`config.json`（运行目录，见 [`config.md`](config.md)）。
- 宠物专属存档：`save.json`（自动生成，含数值、位置、`foodPreferences` 偏好）。
- 性能/窗口：`pet.config.json`。

## 五、如何添加宠物

1. 手动：把宠物包文件夹放入 `UGC\pets\` 或运行目录的 `pets\`；
2. 图形化：可视化菜单 →「添加新 pet」→ 选择文件夹（自动复制进 `pets\`）；
3. 然后「添加到桌面」即可上线。
